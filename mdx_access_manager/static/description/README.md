# Store listing assets (Odoo 18)

These screenshots were captured from the **Odoo 19** build of this module and are
reused here deliberately: the two builds share the same views, so the screens are
identical apart from group terminology (Odoo 19 says "privilege" where 18 says
"application", and 19 can show assigned-vs-effective groups where 18 shows
chosen-vs-inherited).

The matrix caption in `index.html` states this outright rather than leaving a
buyer to discover it. If you would rather capture native 18 shots, the recipe is
in the Odoo 19 copy of this file.
